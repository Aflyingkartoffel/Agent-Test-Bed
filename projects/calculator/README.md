# Calculator

A small, polished browser calculator for the first application in the AI-assisted application development laboratory.

## How to run

Open [`index.html`](index.html) in a modern web browser. No installation, server, dependency, or internet connection is required.

## Features

- Addition, subtraction, multiplication, and division
- Decimal and positive/negative number input
- Standard multiplication/division precedence
- Clear, backspace, equals, and continued calculations
- Graceful division-by-zero and invalid-calculation messages
- Mouse, keyboard, and visible focus support

## Technology used

- HTML for the interface
- CSS for the responsive visual design
- Vanilla JavaScript for state, events, and arithmetic logic

## Current limitations

- It does not yet include a calculation history.
- It does not support parentheses or scientific operations.
- The application is currently tested by inspection and manual browser use rather than automated browser tests.

## Future ideas

- Add a calculation history panel.
- Add parentheses and a more advanced expression editor.
- Add light/dark theme switching and a small automated test suite.
