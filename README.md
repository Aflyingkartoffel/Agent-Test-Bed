# AI-Assisted Application Development Laboratory

This repository is a personal workspace for building applications with help from AI coding assistants. The goal is to learn by making useful software: AI handles much of the implementation, while important programming ideas are explained as they become relevant.

## Repository layout

- `projects/` contains actual applications. Each application gets its own directory and README.
- `experiments/` contains small, disposable coding experiments.
- `docs/` contains broader workflow, architecture, and development-environment notes.
- `PROJECT_STATUS.md` is the current overview of all projects.
- `CHANGELOG.md` records meaningful repository and project changes.
- `LEARNING_LOG.md` records useful programming concepts encountered during development.
- `AGENTS.md` contains instructions for AI coding agents working here.

## Working with projects

Projects are intentionally isolated from one another. To work on an application, open its directory and follow that project's README. The commands for installing dependencies, starting development, testing, and building will be documented there once a project exists.

There is no sample application yet. This repository is ready for the first project to be added deliberately.

## Git and safety

GitHub is intended to be the source of truth for project history. Never commit secrets, credentials, API keys, or other sensitive information. Changes should be made in logical stages and tested when practical. Nothing should be pushed to GitHub without explicit approval.
